# Guess The Card — Android Edition 🎴
A lightweight Android game demonstrating clean Kotlin architecture, ViewBinding, and simple game logic. Designed as a readable, beginner‑friendly sample for mobile development.

---

## 🎯 Purpose
This project showcases:
- Kotlin fundamentals  
- ViewBinding for safe UI access  
- Randomized game logic  
- Clean separation of UI and data classes  

Perfect for portfolio use, teaching examples, or internship submissions.

---

## 🧠 Architecture Overview
### Data Layer
- **Card.kt** — Represents a playing card  
- **Deck.kt** — Builds a full deck and returns random cards  

### UI Layer
- **MainActivity.kt**  
  - Handles user input  
  - Displays results  
  - Controls difficulty modes  

### Layout
- **activity_main.xml**  
  - Simple, readable UI  
  - ViewBinding enabled  

---

## 🕹 Gameplay
1. Select difficulty  
2. Enter your guess  
3. App reveals the card  
4. Play again instantly  

---

## 🛠 Build Instructions
1. Clone the repository  
2. Open in Android Studio  
3. Sync Gradle  
4. Run on emulator or device
